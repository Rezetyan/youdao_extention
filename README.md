# 网易有道翻译键盘快捷键

这是一个 Manifest V3 Chrome 插件，面向网易有道翻译的单词结果页：

`https://www.youdao.com/result?word=hello&lang=en`

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 打开或刷新有道单词结果页。

也可以直接从 `https://www.youdao.com/` 搜索；页面进入结果地址后快捷键会立即生效，无需强制刷新。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| 主键盘区数字 `1` | 收藏或取消收藏当前单词 |
| 主键盘区数字 `2` | 播放英式发音 |
| 主键盘区数字 `3` | 播放美式发音 |
| `A-Z` / `a-z` | 聚焦搜索框并开始输入新单词 |
| `Enter` | 使用有道页面原生逻辑搜索 |
| `Esc` | 清空搜索框、关闭建议下拉框并返回结果页焦点 |

搜索完成后页面会自动移出搜索框焦点。数字小键盘的 `1`、`2`、`3` 不会触发快捷操作。输入框、下拉框或其他可编辑区域获得焦点时，插件不会拦截普通键盘输入；`Esc` 始终用于清空搜索框、关闭有道建议下拉框并返回结果页。收藏功能仍由有道页面处理，未登录时会进入有道登录流程。
